## <img src="assets/icon-workflows.svg" width="30" alt=""> Workflow shelf

*从材料到交付物 · Research, write, render, and check.*

- **[topic2md](https://github.com/LLM-X-Factorer/topic2md)** — a pluggable topic-to-Markdown pipeline for research, citations, images, and publishing integrations.
- **[Meeting Recap Skill](https://github.com/LLM-X-Factorer/diantou-meeting-recap-skill)** · **Workflow example** — sanitized transcripts to reviewable Markdown, PDF, and Feishu card drafts, with DeepSeek Harness tools and contract tests.
- **[Markdown → Slides & Video](https://github.com/LLM-X-Factorer/diantou-md-to-remotion-video-skill)** · **Workflow example** — editable PPTX and audio-timed Remotion video, with checks on the generated artifacts.

## <img src="assets/icon-quests.svg" width="30" alt=""> Quest board

*从一个小问题开始 · Pick a small problem to work on together.*

1. **[Reproduce a tricky agent run](https://github.com/LLM-X-Factorer/diantou-localbuddy-v2/issues)** — bring a minimal example, expected behavior, and a sanitized trace. Help improve recovery and permission boundaries.
2. **[Add an independent SQL evaluation case](https://github.com/LLM-X-Factorer/deepflow-analyst/issues)** — contribute a question, sample data, and the expected result; investigate a query that fails.
3. **[Explore Chinese research sources · topic2md #14](https://github.com/LLM-X-Factorer/topic2md/issues/14)** — compare sources and propose a stable integration. Start with the [plugin contribution guide](https://github.com/LLM-X-Factorer/topic2md/blob/main/CONTRIBUTING.md).

Bug reports, focused adapters, better examples, and clearer documentation are welcome. For a larger change, open an issue to discuss the scope first. 中文 / English 都欢迎。
